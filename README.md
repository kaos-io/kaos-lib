# kaos-lib

`kaos_lib` is the Python library of the platform, and `kaosctl` is its command. You write ML pipeline steps with them:
a step reads data, does work and hands a result on.

Start with the guide, from [Run it](https://storage.googleapis.com/kaos-dev-511509-kaos-lib/docs/run-it.html). It
grows one app a page at a time, to a real pipeline.
