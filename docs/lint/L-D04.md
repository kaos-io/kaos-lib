# L-D04 CopyOutsideContext

**Level: error.** A `COPY` or `ADD` source is one the build cannot read.

## What it checks

The source is an absolute path, climbs out of the build context with `..`, or does not exist in the context. The context of a step is its folder `steps/<name>/`; only `compose-and-validate` is built with the repository root. `COPY --from=...`, URLs and patterns with `*` or `$` are not judged.

## Why it matters

The build fails with `COPY failed: file not found in build context`. A path outside the context works on your laptop only if you build from a different folder.

## How to fix

Keep the files the step needs inside `steps/<name>/` and copy them with a relative path. Code shared by several steps belongs in a package you install (a `pip install` line), not in a `COPY ../shared`.
