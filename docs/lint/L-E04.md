# L-E04 ClientIdentity

**Level: error.** The pipeline sets its own service account or patches a pod, or uses a reserved template name.

## What it checks

`pipeline.py` passes `service_account_name` or `serviceAccountName` (also inside an executor), `pod_spec_patch` or
`podSpecPatch`, or names a template with a name the platform reserves for its HPC (Slurm) follower.

## Why it matters

The platform chooses the account every step runs as and places the pods itself. A pipeline that picks its own account could
run its code with rights it must not have, so the render is refused.

## Example

```python
Container(name="c", service_account_name="admin")
```

## How to fix

Remove it. Use `step(...)` arguments and compute classes to say what a step needs. If the message names a reserved template
name, rename the step or template.
