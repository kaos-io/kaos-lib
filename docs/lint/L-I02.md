# L-I02 LearnedLimits

**Level: info.** A short limit may be shortened further by the platform.

## What it checks

A GPU step has a default `walltime=` under 2 hours (the default of the run form's `<step>-walltime`). After a few runs the platform may ask the site for a shorter limit, to fit the step in sooner.
A limit of 2 hours or more is kept exactly as it is set on the run form.

## How to use it

Nothing to fix. Set the limit you need.
