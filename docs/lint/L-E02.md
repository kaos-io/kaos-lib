# L-E02 TooLongBeyondContinuations

**Level: error.** A resumable step needs more runs than the platform allows.

## What it checks

A resumable GPU step has a default time limit (`walltime=`, the default of the run form's `<step>-walltime`) that needs more
runs than the continuation cap allows. A step continues up to 5 times by default, so 6 runs in all (12 days with a 2-day
longest run); the cap comes from the project and the site.

## Why it matters

After the last allowed run the step would stop with work still to do. The platform refuses it when it is submitted.

## Example

```python
train = step("train", gpu=True, walltime="400h", resumable=True)   # 9 runs of 2 days
```

## How to fix

Shorten the default `walltime=` (and the limit on the run form), or split the work into steps that each fit.
