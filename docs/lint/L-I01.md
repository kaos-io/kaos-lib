# L-I01 NodeSharing

**Level: info.** A GPU step sets no `walltime=` in `pipeline.py`, so the time limit on the run form starts at 4 hours.

## What it checks

A GPU step has no `walltime=` in `pipeline.py`. Every step has a time limit, chosen on the run form in the field
`<step>-walltime`. `walltime=` only sets what the field starts with, and without it the field starts at 4 hours.

## Why it matters

On the HPC (Slurm) site, steps of your project can share a node. A GPU step joins a node that is already running only if
that node has the step's limit and a few minutes left. A limit close to what the step needs therefore shares more often
than the 4 hour default.

## How to use it

Choose the limit on the run form. If this step always needs about the same time, put it in `walltime=`, for example
`walltime="90m"`, so that the form starts with a good default. Nothing is wrong without it.
[GPUs on HPC (Slurm)](../gpus-on-hpc.md) says what sharing means for the step.
