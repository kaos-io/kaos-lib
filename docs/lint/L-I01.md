# L-I01 NodeSharing

**Level: info.** A GPU step declares no time limit, so it cannot share a node.

## What it checks

A GPU step sets no `walltime`. On the HPC (Slurm) site the platform can place a step as a guest on a node another job of your project already holds,
if the host's remaining time covers the guest's limit.

## How to use it

Set a limit if you want the step to be a guest candidate: `walltime="4h"`. Nothing is wrong without it.
