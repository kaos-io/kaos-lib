# L-I01 NodeSharing

**Level: info.** A GPU step declares no `walltime=`, so it uses the default limit of 4 hours.

## What it checks

A GPU step sets no `walltime`. Every step has a time limit: without `walltime=` it is 4 hours.

## Why it matters

On the HPC (Slurm) site, steps of your project can share a node. A step joins a node that another step of your project
already holds only if the node has the step's limit and about six minutes left. A step with the 4 hour default fits less
often, so it more often starts a node of its own.

## How to use it

Give the step a `walltime=` close to what it needs, so that it can join a node that is already running:
`walltime="90m"`. Nothing is wrong without it. [GPUs on HPC (Slurm)](../gpus-on-hpc.md) says what sharing means for the step.
