# L-E08 OldStepCode

**Level: error.** The app carries code from before the current pipelines.

## What it checks

- The app carries a copy of the platform's pipeline code in a folder of its own: an app holds none.
- In a step's folder (`steps/<name>/`), code that takes `--params` on its command line, or reads one of the
  variables the platform no longer sets (`KUBECORE_RUN_ID`, `CHECKPOINT_BUCKET`, `CHECKPOINT_PREFIX`,
  `OUTPUTS_REPO`, `KUBECORE_WORKFLOW_NAME`, `KAOS_LIB_LOCK`, `KUBECORE_DATASET_REF`, `KUBECORE_DATASET_COMMIT`,
  `DATASET_REPO`, `DATASET_REF`, `DATASET_COMMIT`).
- An `app/entry.py` in a folder where nothing calls `step.start()`.

The check reads the files; it never runs them.

## Why it matters

A step is started as `python -m app.entry` with no arguments. Its config, its run and its inputs come from
`step.start()`, and what it hands on leaves through `step.result()`. An app made before the current pipelines does
not run: create it again from the template.

## Example

```python
parser.add_argument("--params", required=True)          # a step takes no arguments
run = os.environ.get("KUBECORE_RUN_ID")                 # not set any more
```
