# L-E09 PlatformConfigGroup

**Level: error.** The app's config still carries the `platform` group, which the platform no longer has.

## What it checks

- `config/config.yaml` names `platform` in its `defaults:` list (`- platform: live`).
- The app has a folder `config/platform/`.

## Why it matters

Up to kaos-lib 0.4 an app's config held a `platform` group with addresses and settings of the platform. Since
0.5 a step gets its data access and its tracking sign-in from the platform when it starts, and never from the
config: they are not in `step.start().params`. A config that still names the group cannot be rendered.

## Example

```yaml
defaults:
  - _self_
  - experiment
  - train
  - platform: live      # remove this line
```

## How to fix

`kaosctl lint --fix` removes the line. Delete the folder `config/platform/` yourself if your app has one. If a
step read a value from `cfg["platform"]`, it no longer needs it: `step.input()`, `step.output()` and
`kaos_lib.mlflow.mlflow()` reach the platform for you. See [Move to kaos-lib 0.5](../migrate-to-0.5.md).
