# L-E09 PlatformConfigGroup

**Level: error.** The app's config carries the `platform` group, which the platform no longer has.

## What it checks

- `config/config.yaml` names `platform` in its `defaults:` list (`- platform: live`).
- The app has a folder `config/platform/`.

## Why it matters

A step gets its data access and its tracking sign-in from the platform when it starts, never from the config: they
are not in `step.start().params`. A config that names the group cannot be rendered. An app made before the
current pipelines is created again from the template.

## Example

```yaml
defaults:
  - _self_
  - experiment
  - platform: live      # not part of the config any more
```
