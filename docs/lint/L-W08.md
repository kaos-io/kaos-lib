# L-W08 AllowedFailureReachesDataset

**Level: warning.** A step says `matrix_allow_failed=True`, and a step after it writes a dataset.

## What it checks

A step with `matrix_allow_failed=True` that is followed, through `needs=` directly or through other steps, by a step
whose `produces=` holds a `dataset(...)`.

## Why it matters

`matrix_allow_failed=True` says that failed runs are acceptable. A failed training then does not stop the pipeline run,
so the dataset is still written and, if it is promoted, becomes the latest version ([Sweeps](../sweeps.md#pick-the-best)).

## Example

```python
train = step("train", kind="train", matrix={"lr": [0.01, 0.001]}, matrix_allow_failed=True, produces=[model("m")])
scores = step("scores", kind="evaluate", needs=[train], produces=[dataset("scores")])
```

## How to fix

Remove `matrix_allow_failed=True`: one failed run then fails the step, and nothing after it runs. Or keep it and let the
step that writes the dataset read every run from `step.upstream("train")` and call `step.skip(reason)` when too few
have `status` `"ok"`.
