# L-D05 StepContract

**Level: error.** The step has no `app/entry.py` (error), or its Dockerfile does not start `python -m app.entry` (warning).

## What it checks

The folder `steps/<name>/` has a Dockerfile but no `app/entry.py`, or the last `ENTRYPOINT` is not `python -m app.entry`.

## Why it matters

The platform starts every step as `python -m app.entry`, with no arguments. Without the module the step cannot start. A different `ENTRYPOINT` is only a warning, because the platform sets the command itself; it matters when you run the image by hand.

## How to fix

Put the code in `steps/<name>/app/entry.py` and end the Dockerfile with `ENTRYPOINT ["python", "-m", "app.entry"]`.
