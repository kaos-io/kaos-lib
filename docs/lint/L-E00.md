# L-E00 NotAnalysable

**Level: error.** The check could not read your pipeline file.

## What it checks

`pipeline.py` is missing, is not valid Python, or is larger than the check reads (1 MiB).

## Why it matters

The other checks need to read the file. Until it can be read, none of them has run, so a clean result would mean nothing.

## Example

```python
with pipeline("p") as p
    a = step("a")        # a colon is missing
```

## How to fix

Fix the syntax error (the finding gives the line), restore the file, or move code out of `pipeline.py` into your steps.
`pipeline.py` should only describe the pipeline's structure.
