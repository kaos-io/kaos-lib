# L-W07 DatasetProducerStaysOnCluster

**Level: warning.** A step asks for a GPU and produces a dataset. It will run on the cluster, not on an HPC (Slurm) site.

## What it checks

A step with `gpu=True` whose `produces=` holds a `dataset(...)`.

## Why it matters

A step that produces a dataset always runs on the cluster. The run form offers it no HPC (Slurm) class. A client who writes
a GPU step for HPC and lets it write a dataset finds this out only when the class list has no HPC class for the step.

## Example

```python
embed = step("embed", kind="transform", gpu=True, produces=[dataset("embeddings")])
```

## How to fix

Nothing is wrong if the cluster is fine for the step. To use HPC for the heavy work, split it in two. The first step does
the heavy work on the GPU and writes an `artifact`. A second, cheap step reads the artifact and writes the dataset.

```python
embed = step("embed", kind="transform", gpu=True, walltime="6h", produces=[artifact("vectors")])
store = step("store", kind="transform", needs=[embed], produces=[dataset("embeddings")])
```
