# L-W03 UnpinnedDataset

**Level: warning.** A dataset reference follows the newest data.

## What it checks

A dataset reference ends in `@latest`: the `dataset:` default in `config/dataset.yaml`, or a string in step code.

## Why it matters

Two runs of the same code can read different data, so results cannot be reproduced or compared. The platform pins the commit a run reads,
but `@latest` still moves between runs.

## How to fix

Release a version of your dataset and use it: `dataset-default@v1`. (A new project's `dataset-default@latest` is fine until you have a first version.)
