# L-W03 DatasetVersionInCode

**Level: warning.** A step's code names a dataset and a version.

## What it checks

A string in a step's code holds a dataset reference with a version: `"dataset-default@latest"`, `"dataset-default@v3"`.
The default version in `config/` is not checked: a setting without a version, or with one, is the normal case.

## Why it matters

The version of a dataset is chosen once, on the run form, and the platform hands every step the exact version it
chose. A step reads only those versions. A version written in code is ignored when the dataset is one of the step's
inputs, and refused when it is not, so the step either reads something other than what its author wrote or fails.

## How to fix

Declare the dataset in `pipeline.py` and read it by its name:

```python
step("train", kind="train", inputs=["dataset"])            # `dataset: dataset-default@latest` in config/
```

```python
data = step.input("dataset")
```
