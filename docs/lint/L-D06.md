# L-D06 HugeLayers

**Level: warning.** Something makes the image much larger than it needs to be.

## What it checks

`COPY . .` of the repository root, a `COPY` of a folder named like data (`data`, `datasets`, `weights`, `runs`, `out`, `.git` ...) or larger than 50 MiB, `pip install` without `--no-cache-dir`, or `apt-get install` without removing `/var/lib/apt/lists` in the same `RUN`.

## Why it matters

A large image is slow to build, to push and to start on a node, and a data folder baked into an image is a copy of your data that nothing keeps up to date.

## How to fix

Copy only what the step runs. Read data at run time with `kaos_lib.datasets`. Use `pip install --no-cache-dir` and `apt-get install ... && rm -rf /var/lib/apt/lists/*`.
