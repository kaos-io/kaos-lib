# L-D07 RootUser

**Level: info.** The image's last stage never sets `USER`, so the step runs as root.

## What it checks

No `USER` instruction after the last `FROM`.

## Why it matters

Running as root is more than most steps need. The platform does not require a non-root user today (neither template sets one), so this is information, not a warning.

## How to fix

If the step does not need root, add `RUN useradd --create-home app` and `USER app` before the `ENTRYPOINT`, and check that the folders the step writes to are writable by that user.
