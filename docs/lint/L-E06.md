# L-E06 RefusedArgument

**Level: error.** A step() argument is one the library refuses.

## What it checks

A `step()` call has an argument the library raises on: an unknown name, `walltime` or `resumable` or
`checkpoint_every` or `idle_timeout` in a wrong form, a keyword given twice, or an argument after the name given by
position (only the name is positional: write `kind="train"`, not `"train"`).

`outputs=`, `hpc_time_limit=` and `disk=` are no longer part of `step()`. An app that still passes one was made
before the current pipelines: create it again from the template.

## Why it matters

The pipeline fails when it is rendered, with a Python error. The check says so before, with the line.

## Example

```python
step("train", kind="train", walltime="12 hours")              # a time has no space: '12h'
step("train", kind="train", colour="red")                     # step() has no such argument
```

## How to fix

Use the form in the message. Times are minutes or hours as text: `'90m'`, `'12h'`, `'720'`.
