# L-E06 RefusedArgument

**Level: error.** A step() argument is one the library refuses.

## What it checks

A `step()` call has an argument the library raises on: an unknown name, `disk` that is not a quantity (`'20Gi'`),
`walltime` or `resumable` or `checkpoint_every` or `idle_timeout` in a wrong form, or `walltime` / `resumable` on a
step that is not `gpu=True`.

Two arguments were removed in kaos-lib 0.5 and are reported here with their fix:

| Removed | Use instead |
|---|---|
| `hpc_time_limit=` | `walltime=`, same values |
| `outputs=` | nothing in `pipeline.py`: the step calls `step.result(...)`, and a step that needs the values reads `step.upstream(...).values` |

## Why it matters

The pipeline fails when it is rendered, with a Python error. The check says so before, with the line.

## Example

```python
step("train", kind="train", gpu=True, hpc_time_limit="12h")   # the argument is walltime
step("prep", kind="transform", disk="20 GB")                  # a quantity has no space: '20Gi'
```

## How to fix

Use the form in the message. Times are minutes or hours as text: `'90m'`, `'12h'`, `'720'`. For the two removed
arguments, `kaosctl lint --fix` rewrites `pipeline.py` for you; see [Move to kaos-lib 0.5](../migrate-to-0.5.md).
