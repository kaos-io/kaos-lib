# L-E06 RefusedArgument

**Level: error.** A step() argument is one the library refuses.

## What it checks

A `step()` call has an argument the library raises on: an unknown name (for example `walltime`; the argument is
`hpc_time_limit`), `disk` that is not a quantity (`'20Gi'`), `hpc_time_limit` or `resumable` or `checkpoint_every` or
`idle_timeout` in a wrong form, or `hpc_time_limit` / `resumable` on a step that is not `gpu=True`.

## Why it matters

The pipeline fails when it is rendered, with a Python error. The check says so before, with the line.

## Example

```python
step("train", gpu=True, walltime="12h")        # the argument is hpc_time_limit
step("prep", disk="20 GB")                     # a quantity has no space: '20Gi'
```

## How to fix

Use the form in the message. Times are minutes or hours as text: `'90m'`, `'12h'`, `'720'`.
