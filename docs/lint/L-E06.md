# L-E06 RefusedArgument

**Level: error.** A step() argument is one the library refuses.

## What it checks

A `step()` call has an argument the library raises on: an unknown name, `walltime` or `resumable` or
`checkpoint_every` or `idle_timeout` or `matrix` in a wrong form, a keyword given twice, or an argument after the name
given by position (only the name is positional: write `kind="train"`, not `"train"`).

`when=` is a run-form field compared with a value, in plain words: `when="quantization-mode != off"`. The check
reports a `when=` that is not written that way (an unknown operator, parentheses, a missing value), one written in the
platform's own `{{workflow.parameters.<field>}}` form, and one that names a field the run form does not have. The
fields are the settings of `config/` as the run form shows them: a setting's path with dashes (`train.epochs` is
`train-epochs`) and one field for each group folder. An app that registers a structured schema declares more
fields in code: a name that starts with one of its sections is then not judged.

`outputs=`, `hpc_time_limit=` and `disk=` are no longer part of `step()`. Each has its own sentence, which says what
to write instead:

- `Step 'x': outputs= is gone. Declare what the step writes with produces=[...] and hand it on with step.result().`
- `Step 'x': hpc_time_limit= is gone. Use walltime=, for example walltime="12h".`
- `Step 'x': disk= is gone. The step gets the disk of the machine class it runs on.`

### `matrix=`

`matrix=` is a dictionary: each name holds the list of values to try, for example
`matrix={"lr": [0.01, 0.001], "batch": [16, 32]}` ([Sweeps](../sweeps.md)). The check says which of these is wrong. Each
message starts with `Step 'x': `.

| What is wrong | The message, after the step | The fix |
| --- | --- | --- |
| `matrix=` is not a dictionary, or is empty | `matrix= is [1, 2]. Write the values to try for each setting, for example matrix={"lr": [0.01, 0.001], "batch": [16, 32]}: the step runs once for each combination.` | Write the values to try for each setting. |
| a name is not lowercase letters, digits and `_` | `matrix= holds the name 'Learning-Rate'. A name is lowercase letters, digits and _, starting with a letter, at most 40 characters: it is how the step reads the value (step.params['lr']).` | Rename it. |
| a name is also a section the step reads | `matrix= has the name 'train', which is also a section the step reads (reads=). Rename one of them: the step would not know which 'train' it reads.` | Rename the name in `matrix=` or the section in `reads=`. |
| a name does not hold a list with a value in it | `matrix= gives 'lr' the value 0.01. Give a list with at least one value, for example 'lr': [1, 2].` | Write a list: `[0.01]`. |
| a value is not a number, `True` or `False`, or a short text | `matrix= value [1] of 'lr' is a list. A value is a number, true or false, or a short text.` or, for a text with other characters than letters, digits, spaces and `. _ + / : = @ , ( ) [ ] # % ^ ~ * -` or longer than 64, `matrix= value 'a{b' of 'opt' is the text 'a{b'. A text value is 1 to 64 letters, digits, spaces and the characters . _ + / : = @ , ( ) [ ] # % ^ ~ * -` | Use numbers, `True` or `False`, or short texts. |
| a value is a whole number beyond 2^53 | `matrix= value 12345678901234567890 of 'seed' is the number 12345678901234567890, which is beyond 9007199254740992 (2 to the power 53): a number that large cannot be kept exactly. Write it as text, for example "12345678901234567890".` | Write it as text. |
| more than 32 combinations | `matrix= makes 36 combinations; a step runs at most 32. Remove values, or split the step.` | Remove values. |
| the step is an `ingest`, `publish` or `control` step | `a step of kind publish runs once, so it cannot have matrix=. Give the step the kind of the work it does (transform, train, evaluate), or remove matrix=.` | Give the step the kind of the work it does, or remove `matrix=`. |
| `produces=` holds a dataset | `a step with matrix= cannot produce a dataset: a dataset has one writer and one version per run. Produce a model or an artifact from the matrix step, and let the step after it write the dataset.` | Produce a model or an artifact, and write the dataset in the next step. |
| the step reads and writes more than 4 things (`inputs=` and `produces=` together) | `a step with matrix= may read and write at most 4 things in all (inputs= and produces= together; it has 5): up to 32 items hand back what they read and wrote in one shared result. Read fewer inputs, or join what the step writes.` | Read and write at most 4 things in all. |
| the step needs two steps that have `matrix=` | `it needs two steps with matrix= (a, b). The results of all the items of a matrix step share a large part of a step's context, so a step may need one of them. Put a step between.` | Put a step between. |
| the step needs a step with `matrix=` and more than 4 steps in all | `it needs 5 steps, one of them with matrix=; a step that needs a matrix step may need at most 4 steps in all. The items' results take 56 KiB of its context. Join some of the steps it needs, or put a step between.` | Need at most 4 steps in all. |
| `matrix_allow_failed=` is not `True` or `False` | `matrix_allow_failed='yes' must be True or False.` | Write `True` or `False`. |
| `matrix_allow_failed=True` without `matrix=` | `matrix_allow_failed=True is for a step with matrix=: it lets the step after it run when some items failed. Add matrix=, or remove matrix_allow_failed.` | Add `matrix=`, or remove `matrix_allow_failed`. |
| the step needs a step that has `matrix=` | `a step with matrix= cannot need another step with matrix=: each combination would need the matching one. Put a step between them that picks the combinations to use.` | Put a step between them that picks the combinations to use. |
| a `when=` reads a value of a step that has `matrix=` | `when= reads a value of step 'train', which runs once for each combination of its matrix= and so has no one value. A when= may read a field of the run form, or a value of a step that runs once.` | Read a field of the run form, or read the values in the step after the matrix step (`step.upstream("train")` is a list). A `when=` on the matrix step itself is allowed. |

A `matrix=` that is not written out as values (a variable, a function call) is not checked.

## Why it matters

The pipeline fails when it is rendered, with a Python error. The check says so before, with the line.

## Example

```python
step("train", kind="train", walltime="12 hours")              # a time has no space: '12h'
step("train", kind="train", colour="red")                     # step() has no such argument
step("export", kind="transform", when="{{workflow.parameters.mode}} != off")   # write the field's name
step("export", kind="transform", when="no-such-field != off")                  # not a field of the run form
step("train", kind="train", matrix={"lr": 0.01})                               # a list: [0.01]
step("train", kind="train", matrix={"lr": [0.01, 0.001]}, produces=[dataset("scores")])   # a dataset has one writer
```

## How to fix

Use the form in the message. A `when=` names a field of the run form: `when="mode != off"`. Times are minutes or hours as text: `'90m'`, `'12h'`, `'720'`. Each message about `matrix=` ends in what to write instead (table above).
