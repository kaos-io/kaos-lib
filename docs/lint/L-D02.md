# L-D02 KaosLibNotInstalled

**Level: error.** The step imports `kaos_lib`, but no `pip install` in its Dockerfile installs `${KAOS_LIB_PACKAGE}`.

## What it checks

The Dockerfile declares `ARG KAOS_LIB_PACKAGE`, the step's code imports `kaos_lib`, and no `pip install` line uses `${KAOS_LIB_PACKAGE}`.

## Why it matters

The image is built, then fails with `ModuleNotFoundError: No module named 'kaos_lib'` (or runs an older copy) when the step starts, after the platform has already scheduled it.

## How to fix

Install the library from the argument:

```dockerfile
RUN pip install --no-cache-dir "${KAOS_LIB_PACKAGE}"
```
