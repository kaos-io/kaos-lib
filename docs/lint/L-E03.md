# L-E03 UnknownClass

**Level: error.** A pinned compute class is not one your project can use.

## What it checks

A raw Hera container pins a compute class (the `platform.kubecore.io/compute-class` annotation) that is not in your
project's list of classes.

## Why it matters

The render is refused with the same message: the pipeline cannot be placed on a machine that does not exist for your project.

## Example

```python
Container(name="c", annotations={"platform.kubecore.io/compute-class": "gpu-xx"})
```

## How to fix

Pin one of the classes your project offers (each step's class dropdown in the run form lists them), or remove the pin and
let the project's default choose.

## Limits of the check

It needs your project's list of classes, so it runs only with `--context` (the gate always has it). Without a list it is
reported as skipped, never as passed.
