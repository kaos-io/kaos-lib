# L-E05 DependencyOrProducer

**Level: error.** A step depends on something that does not exist or comes later, or a name or section is wrong.

## What it checks

One of: `needs=` names a step that is not defined or is defined after it; `needs=` holds text instead of the step variable;
`reads=` names a config section that is not in `config/`; two steps have the same name; a step name is not a valid lowercase
name; raw Hera tasks depend on each other in a cycle.

## Why it matters

The pipeline would fail to render, or run in the wrong order.

## Example

```python
with pipeline("p") as p:
    a = step("a", needs=[b])     # b is defined on the next line
    b = step("b")
```

## How to fix

Define each step before the steps that need it and pass the variables: `needs=[b]`. Use lowercase letters, digits and hyphens for
names. Check the section name against `config/`: a section is a folder of `config/`, a file name, or any top-level key of a
file (one file may hold several sections).

## Limits of the check

Only literal lists are checked: `needs=prev_steps` or steps created in a loop are not judged.
