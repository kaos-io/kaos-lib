# L-D08 NoCudaForGpuStep

**Level: warning.** A step asks for a GPU, but its image shows no CUDA support.

## What it checks

The step is `gpu=True` in `pipeline.py`, its base image is not a CUDA image (no `cuda`, `nvidia`, `pytorch` or `tensorflow` in the name) and neither the Dockerfile's `pip install` lines nor `pyproject.toml` / `requirements*.txt` name a GPU library (torch, tensorflow, jax, cupy, ultralytics ...). This check is a heuristic: it searches text.

## Why it matters

The step gets a GPU on its node and cannot use it: it trains on the CPU and holds a GPU (and its cost) for nothing. A pip `torch` wheel bundles CUDA, so `python:3.12-slim` plus `torch` is fine; `python:3.12-slim` alone is not.

## How to fix

Depend on a GPU library, or use a CUDA base image such as `nvidia/cuda:12.2.0-runtime-ubuntu22.04`. If the step does not need a GPU, remove `gpu=True`.
