No usable container engine was found on this machine (kaosctl looked for docker and podman).
kaosctl builds your step image with an engine that is already installed. It never installs one for you.

What to install (free): Colima
  Official instructions: https://github.com/abiosoft/colima#installation
  Commands to run yourself (Homebrew, https://brew.sh):
      brew install colima docker
      colima start
  Your Mac has an Apple chip and the platform runs amd64 images: building them is emulated and slower. To use Rosetta for it, start Colima with:
      colima start --vm-type vz --vz-rosetta

Alternative (free): Podman
  Official instructions: https://podman.io/docs/installation
  Commands to run yourself:
      brew install podman
      podman machine init
      podman machine start

Docker Desktop also works if you already have it, but it needs a paid subscription for companies with more than 250 employees or more than 10 million US dollars of revenue.

kaosctl did not run any of these commands. After installing, run `kaosctl build` again.
